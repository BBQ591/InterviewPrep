* List
.add()
.add(i, element) // adds element at index i
.get()
.remove(i) // removes element at index i
.remove(Integer.valueOf(element)) // removes by value. we need to make sure to use that class because otherwise, it thinks it is an index
indexOf(x) // getting index of element x
.contains(element) // checking if it is in the list
.subList(from, to) // getting sublist
Collections.sort(list) // sorting
Collections.reverse(list) // reversing
Collections.max(list) // getting max of list
.set(i, element) // sets element at index i

* LinkedList
.addFirst(x)
.addLast(x)
.removeFirst(x)
.removeLast(x)
.peekFirst()
.peekLast()

* HashSet
.add(x)
.remove(x)
.contains(x)

* TreeSet
.remove(element)
.first() // min
.last() // max
.floor(x) // greatest element <= x
.ceiling(x) // smallest element >= x
.lower(x) // largest element < x
.higher(x) // smallest element > x
.pollFirst(x) // remove smallest and return it
.pollLast(x) // remove largest and return it
.headSet(x) // all elements < x
.tailSet(x) // all elements > x
.subSet(from, to) // range view, both values not INDEXES
.descendingSet() // reverse order view
